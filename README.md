💰 MyMoney by AKASH BJ

Personal Tracker with Smart Money Insights 🤖

A simple, fast, and free web-based money tracker that helps you manage your daily income and expenses — with built-in smart insights to improve your spending habits.

---

🚀 Live Demo

👉 https://0xzro.github.io/mymoney-tracker/

---

✨ Features

- ➕ Add income & expenses
- 💰 Real-time balance tracking
- 🗑️ Delete transactions
- 💾 Data saved in browser (localStorage)
- 🤖 AI Money Coach (Smart Insights)
  - Spending summary
  - Overspending alerts
  - Category-based insights
  - Daily saving suggestions
- 📱 Mobile-friendly design
- ⚡ Fast & lightweight (no login, no backend)

---

🧠 Problem It Solves

Many people struggle with:

- Overspending
- No clear money tracking
- Poor financial habits

This tool provides a simple way to track and understand money, without complexity.

📦 How to Use

1. Open the website
2. Add a transaction:
   - Positive = Income
   - Negative = Expense
3. View balance & insights
4. Data is saved automatically
